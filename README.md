🎓 EduMind AI

EduMind AI is an AI-powered academic assistant designed to help students understand concepts, clear doubts, prepare for exams, and learn in a personalized way using AI.

It works as an intelligent study companion where students can ask academic questions and receive simple, understandable explanations.

✨ Features

- 🤖 AI-Powered Chatbot – Ask academic questions and get AI-generated answers.
- 🧠 Concept Explanation – Understand difficult topics in a simple and student-friendly way.
- 👶 ELI10 Mode – Get complex concepts explained in very simple language.
- 📚 Exam & Viva Preparation – Helps students prepare for exams and viva questions.
- 💬 Chat Session Memory – Maintains the conversation context during a study session.
- 📋 Copy & Clear Chat – Easily copy responses or clear the conversation.
- 🔐 Student Login & Sign Up – User authentication for students.
- 📱 Responsive Interface – Designed to work across different screen sizes.

🛠️ Tech Stack

- Frontend: React, TypeScript, HTML, CSS
- Backend: Node.js / TypeScript
- AI: Google AI Studio – Gemini API
- Development: Google AI Studio
- Version Control: Git & GitHub

🚀 How to Run Locally

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder

cd edumind-ai

3. Install dependencies

npm install

4. Configure the Gemini API Key

Create a ".env" file and add your Gemini API key:

GEMINI_API_KEY=your_api_key_here

«Note: Never upload your API key or ".env" file to GitHub.»

5. Build the project

npm run build

6. Start the application

npm start

Open the local URL shown in your terminal to use EduMind AI.
